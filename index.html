Облік пального й техніки — без паперу та зайвого клопоту

ПММ — застосунок для військовослужбовців, відповідальних за облік пально-мастильних матеріалів. Ведіть дорожні листи, закривайте їх і отримуйте готові розрахунки та офіційні документи прямо на телефоні — навіть без інтернету. За бажанням можна увімкнути онлайн-режим для спільного доступу з іншого пристрою.

Можливості

Усе для щоденного обліку — і розширені інструменти, коли вони потрібні

Безкоштовно Базовий облік

Доступно всім користувачам без обмежень і без підписки.

  • Картки техніки: марка, номер, підрозділ, паливо, ємність баків
  • Ведення дорожніх і робочих листів, щоденні записи
  • Автоматичний розрахунок витрати пального й мастил
  • Закриття дорожніх листів з підписом командира підрозділу
  • Нагадування про завершення терміну дії ДЛ і техогляд

Підписка Розширений доступ

Щомісячна підписка через App Store / Google Play відкриває звітність і офіційні документи.

  • Донесення ПММ за обраний період
  • Журнали — Д84 та журнал виходу машин з парку
  • Інфографіка по закритих дорожніх листах
  • Генерація офіційного Дорожнього листа у PDF (Додаток 80)
  • Редагування чужих ДЛ/РЛ і техніки в онлайн-режимі за наданим доступом

Два способи спільної роботи

Опційний спільний доступ до техніки та ДЛ

Застосунок і надалі повністю працює офлайн. Якщо кілька відповідальних осіб мають вести облік однієї й тієї самої техніки — є ДВА незалежних способи це зробити: онлайн-режим через наш сервер (нижче) або спільна робота з даними через власний GitHub-репозиторій (розділ під цим). Можна користуватись будь-яким із них — чи обома одразу для різної техніки.

Варіант 1 — онлайн-режим (наш сервер)

Дані зберігаються на хмарному сервері застосунку (Supabase) — найпростіший спосіб, нічого додатково реєструвати не потрібно.

  • Вмикається вручну в налаштуваннях — без email, телефону чи пароля
  • Перегляд і надання доступу до своїх даних — безкоштовно для всіх
  • Редагування чужих даних (лише за наданим власником дозволом) — потребує Pro-підписки
  • Дані можна повністю видалити з сервера будь-коли прямо в застосунку

Детальніше — у Політиці конфіденційності, розділ «Онлайн-режим».

Варіант 2 — спільна робота через GitHub

Спільна робота з даними через власний GitHub-репозиторій

GitHub — відомий, безкоштовний сервіс для зберігання даних (ним користуються мільйони розробників у всьому світі). «Репозиторій» — це просто приватна тека на GitHub, доступна лише тим, кого ви самі туди запросили. Ця функція доступна і на смартфоні, і на версії для комп'ютера — на будь-якому пристрої застосунку. Замість нашого сервера ваші дані (техніка, дорожні листи) автоматично зберігаються у ВАШІЙ ВЛАСНІЙ такій теці, під вашим власним, безкоштовним обліковим записом GitHub. Розробник застосунку доступу до цих даних не має.

Адміністратор Хто створює репозиторій

Один відповідальний за облік натискає «Створити сервер у GitHub» — застосунок сам, автоматично, створює приватний репозиторій на GitHub (власного пароля вводити не потрібно, вхід через GitHub).

  • Генерує коди запрошення для кожного учасника — просто передайте код колезі (напр. у месенджері)
  • Бачить техніку й дорожні листи КОЖНОГО учасника окремим підписаним розділом — лише перегляд, без можливості редагувати чи видаляти чужі дані, без потреби власноруч зводити паперові дані
  • Може в будь-який момент відключити учасника (доступ зникає) чи перенести його техніку у свої власні дані ("злити")
  • Створення власного репозиторію доступне для користувачів, які придбали підписку

Учасник Хто приєднується за кодом

Отримуєте код запрошення від адміністратора й вводите його в застосунку — приєднання повністю безкоштовне, Pro-підписка для цього не потрібна.

  • Техніка й дорожні листи з вашого пристрою автоматично й регулярно передаються у репозиторій адміністратора, окремим підписаним вашим іменем розділом
  • Чужих даних — ні адміністратора, ні інших учасників — ви НЕ бачите: лише свої власні, як і завжди
  • Відключитись від спільної роботи можна будь-коли самостійно, кнопкою «Відключитися від GitHub» — локальні дані на пристрої не зникають
  • Працює повністю офлайн між синхронізаціями — дані оновлюються, щойно з'являється інтернет

Для кого ця функція: коли кілька відповідальних осіб (напр. кілька водіїв однієї техніки) мають свої окремі пристрої, але комусь одному (адміністратору) потрібно бачити облік усіх одразу — без паперового зведення вручну. Дані передаються без шифрування у приватний репозиторій — докладніше про це в Політиці конфіденційності, розділ «Спільна робота з даними через GitHub».

Підписка

Базовий облік — назавжди безкоштовний

Підписка потрібна лише для звітності й офіційних документів. Оформлюється й скасовується через App Store або Google Play — застосунок не зберігає дані вашої картки і не має власного облікового запису.

Щомісячна підписка

Ціна вказана на сторінці застосунку в App Store / Google Play.

  • Донесення, журнали, інфографіка, офіційний ДЛ
  • Автопродовження, скасування в будь-який момент
Версія для комп'ютера

ПК версія — той самий облік на великому екрані

Той самий застосунок, повністю офлайн за замовчуванням — тепер і для комп'ютера. Зручний перегляд і ведення техніки та дорожніх листів на великому екрані, плюс опційна спільна робота з даними кількох відповідальних осіб через власний приватний GitHub-репозиторій.

Windows ПК версія для Windows

Інсталятор одним файлом, без залежностей.

Завантажити дляWindows (.exe)

Мінімальні системні вимоги:

  • Windows 10 (версія 1809, збірка 17763) або новіше, включно з Windows 11
  • 64-розрядна система (x64) — 32-розрядні й ARM-версії Windows не підтримуються
  • Windows 7 не підтримується
  • Вільне місце на диску: від 300 МБ
  • ОЗП: від 4 ГБ

macOS ПК версія для Mac

Інсталятор одним файлом, без залежностей.

Завантажити дляMac (.dmg)

Мінімальні системні вимоги:

  • macOS 12 (Monterey) або новіше
  • Виключно Apple Silicon (M1, M2, M3, M4 та новіші) — Mac на процесорах Intel не підтримуються
  • Вільне місце на диску: від 300 МБ
  • ОЗП: від 8 ГБ

macOS-версія підписана сертифікатом Developer ID і нотаризована Apple — відкривається без жодних попереджень системи безпеки. Інсталятор для Windows поки без цифрового підпису видавця — при першому запуску Windows SmartScreen може показати попередження «Невідомий видавець»: натисніть «Докладніше» → «Виконати в будь-якому разі».
