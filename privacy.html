Політика конфіденційності

Дата останнього оновлення: 10.10.2026

Застосунок «ПММ» (Облік пального) розроблено з максимальною повагою до приватності користувача. За замовчуванням застосунок працює повністю офлайн. Додатково є два опційні механізми обміну даними — онлайн-режим (розділ 2) і анонімна діагностика помилок (розділ 3), кожен з яких користувач вмикає сам і може вимкнути в будь-який момент.

1. Офлайн-режим (за замовчуванням)

Уся інформація, яку ви вводите (дані про техніку, дорожні листи, журнали, розрахунки), за замовчуванням зберігається виключно локально на вашому пристрої у внутрішній базі даних застосунку. Доки онлайн-режим вимкнено, ці дані нікуди не передаються. Реєстрація облікового запису для базового використання не потрібна і не передбачена.

2. Онлайн-режим (опційно)

Онлайн-режим — окрема функція, яку користувач вмикає власноруч у налаштуваннях застосунку. Її мета — дозволити переглядати чи редагувати записи техніки й дорожніх листів з іншого пристрою (наприклад, коли двоє співробітників працюють з тими самими даними).

  • При увімкненні застосунок генерує анонімний ідентифікатор пристрою та секретний ключ доступу. Ім'я, номер телефону, e-mail чи інші персональні дані для цього не потрібні — єдине, що можна додатково вказати, це довільний нік для відображення іншим користувачам.
  • Дані технік/дорожніх листів, якими ви вирішили поділитись, зберігаються на захищеному хмарному сервері (інфраструктура Supabase, розміщена в ЄС) — див. розділ 6 щодо субпроцесора.
  • Перегляд чужих даних, якими з вами поділились, безкоштовний для всіх користувачів. Редагування чужих даних (коли власник явно надав такий дозвіл) доступне лише користувачам з активною Pro-підпискою — самому власнику даних підписка для цього не потрібна.
  • Доступ до ваших даних отримують лише ті пристрої, яким ви самі явно надали дозвіл (за анонімним ідентифікатором/ніком) — доступу "за замовчуванням" немає.
  • Вимкнути онлайн-режим і повністю видалити свої дані з сервера можна будь-коли прямо в застосунку (Меню → блок онлайн-режиму → «Видалити дані на сервері»), без звернення до підтримки.

3. Спільна робота з даними через GitHub (версія для комп'ютера, опційно)

У версії застосунку для комп'ютера (Windows/macOS) є ще одна опційна функція обміну даними — «Спільна робота з даними», незалежна від онлайн-режиму (розділ 2). Власник створює ВЛАСНИЙ приватний репозиторій на github.com під своїм обліковим записом GitHub і запрошує туди інших учасників кодом запрошення.

  • Дані техніки й дорожніх листів учасників зберігаються в цьому репозиторії без шифрування — приватний репозиторій на довіреному обліковому записі власника вважається достатнім захистом для цього сценарію.
  • Репозиторій і токен доступу до нього належать і керуються самим власником. Розробник застосунку не має доступу до цих даних і не зберігає їхню копію на власних серверах — дані проходять напряму між пристроями учасників і GitHub.
  • GitHub (сервіс компанії Microsoft) є інфраструктурним постачальником для цієї функції на умовах власної політики конфіденційності GitHub — див. розділ 6.
  • Функція повністю опційна й вимикається в будь-який момент кнопкою «Відключитися від GitHub» у застосунку; локальні дані на пристрої при цьому не зачіпаються.

4. Дані про помилки застосунку (діагностика)

Щоб виявляти й виправляти технічні збої, застосунок автоматично надсилає анонімні звіти про помилки (текст винятку, стек викликів, версію застосунку, платформу — Android/iOS) на той самий сервер. Для цього використовується окремий випадковий ідентифікатор пристрою, не пов'язаний з вашим ім'ям, обліковим записом магазину застосунків чи ідентифікатором онлайн-режиму, і такий, що не дозволяє встановити особу користувача. Ці звіти доступні лише розробнику застосунку і не публікуються.

5. Дозволи, які використовує застосунок

  • Інтернет/мережа — використовується лише для роботи онлайн-режиму (розділ 2), спільної роботи з даними через GitHub на версії для комп'ютера (розділ 3) та надсилання анонімних звітів про помилки (розділ 4), і лише за наявності з'єднання. Базовий функціонал працює без мережі повністю.
  • Датчики руху (акселерометр) — використовуються лише локально для анімації індикатора рівня пального та реакції на струшування пристрою. Дані з датчиків нікуди не передаються і не зберігаються.
  • Доступ до фото/галереї — використовується лише тоді, коли ви самі експортуєте зображення дорожнього листа чи звіту, щоб зберегти файл у вашу галерею.
  • Сповіщення — локальні нагадування (наприклад, про закінчення терміну дії дорожнього листа чи наближення техогляду), формуються і показуються повністю на пристрої.

6. Підписка та платежі

Оформлення та обробку платежів за підписку здійснює виключно Apple App Store або Google Play — відповідно до їхніх власних політик конфіденційності. Розробник застосунку не отримує і не зберігає дані вашої платіжної картки, а отримує лише факт наявності активної підписки (потрібної, зокрема, для редагування спільних даних інших користувачів в онлайн-режимі — див. розділ 2).

7. Треті сторони

Застосунок не використовує рекламні мережі чи будь-які інструменти відстеження поведінки користувача (аналітичних SDK немає).

Для роботи онлайн-режиму та зберігання анонімних звітів про помилки застосунок використовує Supabase — стороннього постачальника хмарної бази даних (субпроцесор розробника). Supabase зберігає лише ті дані, що описані в розділах 2 і 4 цієї політики, і не має самостійного доступу до локальних офлайн-даних вашого пристрою.

Для спільної роботи з даними на версії для комп'ютера (розділ 3) застосунок використовує GitHub — виключно репозиторій, який належить і керується самим власником даних, не розробником застосунку.

8. Видалення даних

Видалення застосунку з пристрою повністю й безповоротно видаляє всі локальні (офлайн) дані.

Якщо був увімкнений онлайн-режим, дані додатково зберігаються на сервері, доки ви самі не видалите їх через Меню → блок онлайн-режиму → «Видалити дані на сервері» в застосунку (незалежно від видалення самого застосунку з пристрою) — або звернувшись за контактами в розділі 11.

Якщо була увімкнена спільна робота з даними через GitHub (розділ 3), видалення даних із власного репозиторію — дія самого власника репозиторію засобами GitHub (видалити репозиторій чи файл учасника) або кнопкою «Відключитися від GitHub» у застосунку для цього пристрою.

Анонімні звіти про помилки (розділ 4) не прив'язані до особи чи акаунта, тому їх адресне видалення за запитом технічно неможливе; вони автоматично не містять персональних даних.
