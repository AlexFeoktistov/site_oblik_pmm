# Сайт застосунку ПММ (Облік пального)

Простий статичний сайт: чистий HTML/CSS/JS, без збірки та залежностей.

## Структура

- `index.html` — головна сторінка (можливості, як це працює, підписка)
- `contacts.html` — контакти й FAQ
- `privacy.html` — політика конфіденційності
- `terms.html` — ліцензійна угода користувача (EULA)
- `assets/css/style.css` — усі стилі
- `assets/img/` — іконка застосунку та фавікони

## Запустити локально

Будь-який простий статичний сервер підійде, наприклад:

```bash
cd pmm-website
python3 -m http.server 8080
```

Потім відкрити http://localhost:8080 у браузері.
